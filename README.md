# 🚀 DevOps Master Project

An end-to-end DevOps project demonstrating application development, containerization, CI/CD automation, Kubernetes deployment, code quality analysis, and monitoring.

## 🛠️ Technologies

- Java / Spring Boot
- Maven
- Git / GitHub
- Docker
- Docker Compose
- Jenkins
- SonarQube
- Kubernetes
- Prometheus
- Grafana

## 🔄 DevOps Workflow

GitHub → Jenkins → Maven → SonarQube → Docker → Kubernetes → Prometheus → Grafana

## 📊 Monitoring

Grafana provides Kubernetes resource monitoring for CPU, memory, network and storage.

## ☸️ Kubernetes

The project includes Kubernetes deployment and service configurations for the application.

## 🐳 Docker

Docker and Docker Compose are used for containerization and multi-container deployment.

## 🔄 CI/CD

Jenkins automates build, code-quality analysis, Docker image creation and Kubernetes deployment.
